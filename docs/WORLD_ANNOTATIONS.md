# VR World 標註與 agent 物件設計說明

這份文件把空間中的創作標註整理為可重製的物件、狀態與互動規格。標註是設計資料，不是要執行的指令或程式碼。成品只有玩家遊戲，不包含編輯器、帳號、伺服器、遠端儲存或場景修改工具。

## 世界與座標

房間為 10 × 10 公尺，地面 y = 0、天花板高度約 3.2 公尺；Y 向上、旋轉為繞 Y 軸的弧度。場景明亮溫暖，米白牆、木色桌面。幾何尺寸直接寫入網格，避免用縮放造成碰撞誤差。權威位置資料在 `src/world.json`，不需要私有服務。

## 遊戲流程與控制

進入即為自由參觀、計時為零。啟動台浮現「現在可以自由查看、如果準備好就按下啟動台的按鍵」，並提示點選啟動台開始。只有啟動中央啟動台才開始計時和藥袋破裂。五站必須依序完成，做錯目標或距離過遠不能跳關。

WASD 移動；電腦游標自由移動，按住右鍵拖曳環視。游標停留顯示物件名稱、左鍵圖示與操作；左鍵點選拿起／開啟／閱讀，持物時左鍵使用或點指定標誌放置。F 保留中央準星操作。一般家具只顯示名称不能操作。手機左搖桿移動、右搖桿環視，可同時操作；保留滑動環視和兩個動作按鈕。短按且位移不超過 10 CSS 像素才算直接點物件，拖曳與取消觸控不啟動動作。射線取第一個可見表面，保留距離、遮擋及五站順序限制。Esc／暫停按鈕開啟選單並停止計時；離開頁面也會暫停。手機控制避開裝置安全區。計時右上角，電腦物件提示跟隨游標。下列 F 操作也可用左鍵或手指直接點物件完成。

1. **立即通報**：F 拿大聲公，左鍵廣播。播放完提示「左鍵放下麥克風」，留在手上直到玩家放回原位；然後前往第二站。沒有錄音或語音上傳。
2. **封鎖現場**：F 拿黄色警示牌，展開；對準桌旁地面光圈按左鍵放下，必須站立。
3. **穿戴防護**：F 拿防護組，左鍵穿上。手套與袖子在第一人稱可見。
4. **安全清理**：F 開處理盒，在靠近玩家的盒旁生成一片可拿取的毒物吸附墊。F 拿墊，對準桌面污染光圈按左鍵放置。光圈包含裂開的化療藥袋與模擬藥液；吸附墊放置後留在桌上。
5. **廢棄物處理**：F 拿紅色滿袋，對準黄色桶左鍵投入；袋子有短拋入動畫，完成後停止計時並顯示總時間。

重新開始還原所有原始位置、關閉處理盒、移除新生墊片與液滴、脫下手套、恢復完整懸掛藥袋及零計時。遊戲中的拿放不會修改 world.json。

## 從標註轉成物件設計

| 原標註意圖 | agent 應實作與驗收的結果 |
|---|---|
| 把旁邊桌上的化療藥物袋掛在點滴架上 | 既有袋移到點滴架掛鉤；袋的吊孔對齊掛鉤，直立懸掛，標籤朝房間內。不要複製成兩袋。 |
| 藥袋需要啟動破裂 | 中央啟動台開始時，懸掛袋底出現裂口與垂落碎片，模擬藥滴下落，地面形成逐漸擴散的藥液；不要讓液體漂浮在袋子高度。 |
| 製作大聲公，可靠近嘴巴廣播 | 有喇叭筒、握把及麥克風部位；握持手勢正確，播中文通報範例，結束後提示放回。 |
| 警示牌桌上為收折平放，拿起就站立 | 收折與展開是兩個明確幾何姿勢；碰撞尺寸同步更新，不可只是改文字。 |
| 防護裝備可穿到玩家身上，手套可見 | 桌上裝備組拿起後穿戴，第一人稱雙手顯示手套與袖口；重開還原。 |
| 打開處理包後出現吸附墊 | 上蓋打開；可拿取的墊片生成於盒子靠玩家側約 0.48 公尺，不能躲在盒後；重複開盒不重複生成。 |
| 加入装滿醫療廢棄物的紅袋，丟入黃色桶 | 滿袋有清楚輪廓、束口與標籤，拿起後左鍵投入桶；不得把空袋當成滿袋目標。 |

桌面需要支撐上方物件，因此本版桌子維持站立；收折動作只套用到警示牌。物件外觀的「原態／啟動態」是設計概念，公開遊戲不提供編輯切換介面。

## 五站說明牌內容

- 第一站：立即通報。保持鎮定，並大聲通知現場人員。
- 第二站：封鎖現場。標示並控制污染範圍，防止藥物擴散或被踩踏。
- 第三站：穿戴防護。穿著合適的個人防護裝備，避免皮膚與呼吸道直接暴露。
- 第四站：安全清理。使用潑灑處理套組中的吸水材質覆蓋、吸附藥液；完整既有牌面見 `src/notices.json`。
- 第五站：廢棄物處理。將使用過的清理用品與防護裝備放入危害性廢棄物袋，依規定處理並洗手。

這是教學情境遊戲，實際作業遵循院內規範與受訓指導；通關計時不是臨床能力認證。

## 給 agent 的製作流程

1. 讀本文件和 world.json，先確認每個物件的用途、尺寸、位置、朝向、原態和啟動態。
2. 在 `src/models` 或物件專用檔建立程序化幾何；材質、標籤和碰撞須能在單檔中運作，不引入需要憑證的資源。
3. 使用物件 kind 綁定明確的遊戲事件，不把任意標註文字當作可執行程式。
4. 以 `published-game.ts` 的順序與距離／落點判斷連接操作；效果放在 `object-actions.ts` 或 `game-view.ts`，不要修改原始布局。
5. 逐一檢查手持遮擋、標籤可讀性、桌面支撐、掛鉤對齊、碰撞及重設清理。
6. 完成桌面與觸控全流程、離線單檔與 CSP 驗證後，重建根目錄 index.html。

目前發布的是第一人稱 3D 空間遊戲；「VR World」指空間式世界與標註規格，不代表已驗證頭戴式 WebXR 裝置。
